# Лендинг личного бренда `_angrove_`

Премиальный одностраничный конверсионный лендинг личного бренда **«_angrove_»** (Андрей, автоматизация бизнеса: AI-агенты, AI-обзвон, парсеры, автоматизации).

Сайт спроектирован по методологии **Mobile-First** (адаптирован под мобильный трафик из Instagram и Telegram, проверен на ширине 390 px и десктопе 1440 px), со строгим соблюдением бизнес-фокуса для владельцев компаний.

## 🎨 Дизайн-система

- **Цветовая палитра**:
  - `ink` (`#0A0E1C`): Глубокий ночной фон
  - `surface` (`#151A33`): Карточки и подложки
  - `line` (`#2A3050`): Границы и разделители
  - `light` (`#F0EEF7`): Светлые чередующиеся блоки
  - `text-dark` (`#0B0F1E`): Текст на светлом фоне
  - `accent` (`#3D5CFF`): Электрический синий (фирменный пиджак)
  - `accent-bright` (`#617DFF`): Неоновый синий акцент
  - `ice` (`#BFD4FF`): Ледяной голубой
  - `success` (`#22C55E`): Зеленый статус
  - `warning` (`#F59E0B`): Предупреждения
- **Типографика**:
  - Локальный шрифт **Onest** (заголовки 800–900 black, наборный текст 400–500)
  - **JetBrains Mono** для бейджей, цифр, терминальных блоков и кода
- **Фирменные графические элементы**:
  - Бесшовный SVG-паттерн леопардового принта (`#A8B4D6`, `#262A36`, `#7686B8`) в виде разделителей секций и акцента шапки
  - Duotone-обработка реального фото Андрея (B&W + синий оверлей в рамке с мягким свечением)
  - Чисто кодовые иллюстрации интерфейсов (без чужих торговых марок и стоковых фото)

## 🚀 Быстрый старт

### Требования
- Node.js 18+ (рекомендуется Node.js 20 или 22+)
- npm, pnpm или yarn

### Установка зависимостей
```bash
npm install
```

### Запуск в режиме разработки
```bash
npm run dev
```
Сервер запустится по адресу [http://localhost:5173/](http://localhost:5173/).

### Сборка для продакшена
```bash
npm run build
```
Команда собирает оптимизированный бандл в папку `dist/` и автоматически генерирует `dist/privacy/index.html` и `dist/404.html` для корректной маршрутизации на статическом хостинге.

### Локальный просмотр продакшен-сборки
```bash
npm run preview
```

## ⚙️ Чек-лист перед запуском в продакшен

Перед публикацией сайта замените следующие плейсхолдеры:

### 1. Переменные окружения (`.env` или настройки хостинга)
Создайте файл `.env` на основе `.env.example`:
```env
# Ссылка на ваш Telegram (для кнопок "Обсудить задачу")
VITE_TELEGRAM_URL=https://t.me/angrove

# Ссылка на ваш Instagram (для кнопки в блоке "Обо мне")
VITE_INSTAGRAM_URL=https://instagram.com/angrove

# Webhook-эндпоинт для сбора лидов из формы гида (Make, n8n, CRM или собственный сервер)
# Если оставить пустым, форма симулирует успешную отправку для тестирования
VITE_FORM_ENDPOINT=https://hook.eu2.make.com/your-real-webhook-url

# Номер счетчика Яндекс.Метрики
VITE_YANDEX_METRIKA_ID=99999999
```

### 2. Замена файлов в папке `public/`
- `public/andrey.jpg` — замените на актуальную фотографию Андрея высокого качества (пропорции 4:5 или 1:1, duotone-эффект применится автоматически).
- `public/guide.pdf` — замените на актуальную финальную версию PDF-гида «Как заставить программы работать вместо вас».
- `public/favicon.svg` — фирменный фавикон с монограммой `_a_`.

### 3. Реквизиты в Политике конфиденциальности (`/privacy`)
Откройте файл [`src/pages/PrivacyPage.tsx`](file:///Users/angrove/.gemini/antigravity/scratch/angrove-landing/src/pages/PrivacyPage.tsx) и заполните данные:
- `[ФИО / Наименование ИП / Самозанятый]`
- `[Ваш ИНН]`
- `[contact@angrove.ru]`

## 🚢 Деплой

### 1. Vercel (Рекомендуется)
1. Установите Vercel CLI (`npm i -g vercel`) или подключите Git-репозиторий в панели vercel.com.
2. Команда сборки: `npm run build`
3. Директория вывода: `dist`
4. Добавьте переменные окружения из раздела `.env`.

### 2. Netlify
Создайте `netlify.toml` в корне или укажите в веб-интерфейсе:
- Build command: `npm run build`
- Publish directory: `dist`

### 3. Nginx / VPS
Для обслуживания статики настройте конфигурационный блок:
```nginx
server {
    server_name angrove.ru www.angrove.ru;
    root /var/www/angrove-landing/dist;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }

    location ~* \.(jpg|jpeg|png|gif|ico|css|js|woff2|pdf|svg)$ {
        expires 30d;
        add_header Cache-Control "public, no-transform";
    }
}
```
